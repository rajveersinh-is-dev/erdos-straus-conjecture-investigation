Mathematical investigation of the Erdős–Straus conjecture: exact criterion, hard-core reduction, Type I/II dichotomy, and new parametric families.

## Overview

`erdos-straus-conjecture-investigation` provides algorithmic implementations and mathematical models for scientific and cryptographic applications, focusing on numerical stability, invariant verification, and performance.

## Getting Started

```bash
git clone https://github.com/rajveersinh-is-dev/erdos-straus-conjecture-investigation.git
cd erdos-straus-conjecture-investigation
pip install -r requirements.txt
```

Run the automated verification suite:

```bash
pytest tests/
```
